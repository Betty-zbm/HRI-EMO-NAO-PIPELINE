Adaptive Cross-modal Transformer (HRI-EMO)

Analyses audio and text jointly with bidirectional cross-modal attention and a β-gate that dynamically weights each modality by reliability, followed by an emotion-level Transformer decoder. Speech is transcribed live with Whisper; audio and text features are extracted online per checkpoint (WavLM+BERT or COVAREP+GloVe).

Not sure which to choose?

MELD 4-class — recommended default: trained on real conversational dialogue, so it best matches how people naturally talk to a robot, and it tolerates background noise.

IEMOCAP 4-class — strongest on clean, deliberate speech: quiet lab room, participants close to the microphone expressing emotions clearly (it was trained on acted recordings).

Binary sentiment (MELD / MOSEI) — negative vs non-negative (the non-negative class includes neutral speech): the most reliable choice when you only need to detect negative affect.

MOSEI 6-emotion — the only multi-label option: captures co-occurring emotions (e.g. sad + angry) for higher emotional-intelligence scenarios. Note the latency: COVAREP feature extraction runs in a MATLAB subprocess (~7 s per utterance, plus a one-time GloVe load of several minutes on the first request), so it is not recommended for live robot interaction. It shines when real-time response is not required — e.g. analysing participants' recorded audio after an experiment session. It also needs MATLAB/COVAREP + GloVe installed on the server.

Enter the server IP above and click “Generate Script”.
  1. In Choregraphe, drag a Python Script box into your behaviour and double-click it.
  2. Replace the box's entire code with the generated script (it defines __main__(app)).
  3. Wire the box after a start trigger (e.g. a tactile-head touch or dialog event) and run the behaviour.
  4. NAO says “I am listening”, records until you stop speaking (max 10 s), uploads the WAV to /predict, and speaks the result.
  5. To change checkpoint or output settings later, just save them on the Model Settings tab — the robot script never needs to change.
